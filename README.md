# Tourism Review Emotion Analysis and Drift Detection

## Overview

This repository contains the code and results for an MSc thesis analysing emotional changes in online tourism reviews from **10 destinations between 2019 and 2024**.

The study uses NLP, machine learning and statistical methods to classify emotions, measure monthly emotional drift, detect unusual changes and investigate their possible association with external events.

## Research Objectives

- Classify tourism reviews into seven emotions.
- Analyse monthly emotional patterns across cities and attractions.
- Measure and detect unusual emotional changes.
- Investigate possible external events associated with selected changes.

## Dataset

- **Destinations:** 10
- **Attractions:** 48
- **Period:** 2019–2024
- **Preprocessed reviews:** 22,092
- **Usable reviews for drift analysis:** 22,085

## Methodology and Notebooks

The project consists of seven notebooks, executed in the following order:

| Notebook | Description |
|---|---|
| **1_DataLoad.ipynb** | Loads and combines tourism review datasets. |
| **2_preprocessing.ipynb** | Cleans review data, handles languages and prepares text for analysis. |
| **3_EmotionAnalysis.ipynb** | Classifies reviews into seven emotions using a pretrained DistilRoBERTa model. |
| **4_EmotionalDriftAnalysis.ipynb** | Measures monthly emotional drift and detects unusual changes at city level. |
| **5_EventMapping.ipynb** | Investigates selected drift episodes and their possible links to external events. |
| **6_PlaceLevelDriftAnalysis.ipynb** | Analyses emotional drift at individual attraction level. |
| **7_TourismDrift_Visualization_Analysis.ipynb** | Generates figures and visual summaries of the research findings. |

## Models and Techniques

| Model / Technique | Purpose |
|---|---|
| fastText | Language detection |
| DistilRoBERTa | Seven-class emotion classification |
| Mean aggregation | Monthly emotion profiles |
| Jensen–Shannon distance | Primary emotional drift measurement |
| Cosine distance | Alternative drift measurement |
| Median Absolute Deviation (MAD) | Robust variability estimation |
| Robust Z-score | Detection of unusual drift |
| TF-IDF | Keyword analysis |
| Permutation testing | Statistical assessment of selected attraction-level differences |
| Benjamini–Hochberg correction | Multiple-testing correction |

### Emotion Categories

The classifier predicts seven emotions:

1. Anger
2. Disgust
3. Fear
4. Joy
5. Neutral
6. Sadness
7. Surprise

## Key Outputs

- Preprocessed tourism review dataset.
- Emotion-classified review dataset with seven probability scores.
- City-level monthly emotional drift results.
- Attraction-level emotional drift results.
- Candidate drift episodes and external event mapping.
- Statistical summaries, figures and visualisations.

## Running the Project

1. Clone or download the repository.
2. Open the project in Jupyter Notebook, JupyterLab or Visual Studio Code.
3. Install the required Python libraries.
4. Ensure the input datasets are available in the `Data/` directory.
5. Run the notebooks sequentially from `1_DataLoad.ipynb` to `7_TourismDrift_Visualization_Analysis.ipynb`.

Each notebook uses outputs generated by earlier stages of the workflow.

## Limitations

- The emotion classifier is pretrained and not fine-tuned on the tourism dataset.
- Predicted emotions represent model-estimated emotional language, not verified tourist emotions.
- Review volume and temporal coverage vary across destinations.
- Detected drift does not necessarily indicate a meaningful tourism event.
- External event mapping identifies possible contextual associations, not causal relationships.
